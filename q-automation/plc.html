Familias de PLC Wecon

Quark-Systems ofrece todas las principales series de PLC Wecon, desde controladores compactos hasta sistemas modulares avanzados. Nuestro equipo te ayuda a elegir el PLC correcto según velocidad, redundancia, I/O y expansión.

  • PLC LX3VP

    Compacto y rentable, ideal para líneas medianas y automatización estándar.

    • 64k steps de programa
    • Pulsos hasta 200 kHz
    • Red N:N (2–8 PLCs)
    • Capacidad de expansión modular
    Ver en WECON

  • PLC LX5V

    Optimizado para motion-control, con gran precisión y velocidad.

    • 8 ejes de pulsos simultáneos
    • Ejecución de 0.01-0.03 µs
    • Comunicación a alta velocidad
    • Compatibilidad con módulos LX3V
    Ver en WECON

  • PLC AC60 (Codesys)

    PLC con I/O de alta velocidad y EtherCAT integrado, para sistemas avanzados.

    • 4 entradas 200 kHz + 4 AB + 4 salidas 200 kHz
    • Doble Ethernet + EtherCAT
    • Memoria de programa: ~50 MB + 10 MB para variables
    • Ampliable con módulos Wecon
    Ver AC60

  • PLC LX6V

    Alta performance para aplicaciones críticas y procesos exigentes.

    • Ciclo ultrarrápido (0.01–0.02 µs)
    • EtherCAT integrado + USB-C
    • Memoria de programa de 5 MB
    • Hasta 64 módulos en expansión
    Ver LX6V

PLC A500 – Modular Avanzado

Disponibilidad total: CPU y fuente redundantes, módulos de seguridad, redes industriales.

  • Redundancia CPU + fuente
  • Doble EtherCAT / ProfiNet / Modbus TCP
  • Módulos de seguridad SIL3 / PL-e
  • Arquitectura modular completa y escalable
Ver A500

Expansión modular Wecon
