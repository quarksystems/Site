Series principales de PLC Wecon

Presentamos las series de PLC más utilizadas en automatización industrial. Cada una está optimizada para un tipo de aplicación: alto rendimiento, motion, control general o arquitectura modular avanzada.

  • PLC Serie LX6V

    Máxima potencia de proceso para aplicaciones críticas.

    La serie LX6V es la línea de alto rendimiento de Wecon. Ideal para maquinaria compleja, líneas de producción exigentes y sistemas con necesidades de ejecución ultrarrápida.

    • Tiempo de ciclo extremadamente bajo (0.01–0.02 µs).
    • EtherCAT integrado + USB-C para configuración inmediata.
    • Memoria de programa hasta 5 MB.
    • Soporte de hasta 32 módulos (64 con expansión de potencia).
    Ver en WECON

  • PLC Serie LX5V

    Diseño optimizado para motion control y sincronización precisa.

    Perfecta para envasadoras, CNC pequeños, robots cartesianos, etiquetadoras y sistemas donde la velocidad y el control de ejes son la prioridad.

    • Hasta 8 ejes simultáneos de pulsos de alta velocidad.
    • Ejecución de 0.01–0.03 µs.
    • Comunicaciones hasta 921,600 bps.
    • Compatible con módulos LX3V para expansión económica.
    Ver en WECON

  • PLC Serie LX3VP

    Equilibrio ideal entre costo, prestaciones y escalabilidad.

    El PLC más versátil del portafolio: compacto, económico y expandible. Adecuado para líneas medianas, automatización general y proyectos con crecimiento planificado.

    • 64k steps y funciones avanzadas.
    • Pulsos de 200 kHz de alta precisión.
    • Red N:N entre 2 y 8 PLCs.
    • Módulos de expansión analógicos, digitales y comunicación.
    Ver en WECON

PLC Serie A500

Arquitectura modular avanzada para automatización de gran escala.

La serie A500 es el sistema más completo de WECON. Incluye redundancia, módulos de seguridad SIL3, comunicaciones industriales de alto nivel y capacidades propias de controladores de gama premium.

  • CPU y fuente redundante: alta disponibilidad real.
  • Doble red EtherCAT + ProfiNet + Modbus TCP.
  • Módulos de seguridad SIL3 / PL-e.
  • IoT nativo con monitoreo remoto.
